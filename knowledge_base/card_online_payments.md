# Online card payments

Fictional Demo Finance policy for a local portfolio demonstration.

## Online payment declined

1. Describe the displayed error with sensitive details removed and whether the merchant requested payment verification. Do not ask again if these details have already been supplied.
2. Check the online payment setting, expiry date and card status in the app. Enter payment details only on the merchant's legitimate checkout page, never in a support message.
3. A declined payment does not prove that a charge was made or reversed. Only an authorized transaction record can confirm an individual payment's status; this demo cannot access it.

## Payment verification code missing

1. Check your network signal and the phone number shown in the app.
2. Request a new code from the payment verification screen.
3. If the code is still missing, contact support with the merchant name and approximate attempt time.
4. Never share the verification code or bypass verification. These steps do not prove that the payment succeeded.
