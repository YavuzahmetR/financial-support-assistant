# Fictional card support knowledge base

These manually written policies describe **Demo Finance**, an invented institution.
Their delivery estimates, app screens and procedures are fictional; they are not
real banking policy. Every reply requires a support worker's review.

The five files cover physical-card delivery, activation, damage and shop/online
payment problems. They contain no customer records and cannot establish an
individual account, shipment or payment status.

Each `##` section is one searchable passage. Its identifier uses the filename and
section heading, so keep those names stable: application rules refer to them.
The reader also records the file and line numbers for the interface's sources.
Titles, introductory notices and this README are excluded from search.
